# Destination LMS

## Description
A comprehensive Learning Management System (LMS) platform built with JavaScript. Features course management, student enrollment, progress tracking, and interactive learning tools.

## Features
- Course Management
- Student Enrollment
- Progress Tracking
- Interactive Learning Tools

## Installation
1. Clone the repository: `git clone https://github.com/helaluddin-swe/destination-lms.git`
2. Navigate into the project directory: `cd destination-lms`
3. Install dependencies: `npm install`

## Usage
- Start the application: `npm start`
- Open your browser and navigate to `http://localhost:3000`
